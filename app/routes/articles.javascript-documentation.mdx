## Introduction to JavaScript and ECMAScript

JavaScript (JS) is a high-level programming language developed in 1995 by Brendan Eich. ECMAScript (ES) is the standardized version of JavaScript, governed by ECMA International. The two terms are often used interchangeably.

Over time, JS evolved with additions like jQuery, Node.js, and modern ECMAScript standards (ES6+), making it more powerful and suitable for both client and server-side development.

## Hello World in JavaScript

To attach JS to HTML:

```html
<script src="myscript.js"></script>
```

Or directly embed JS:

```html
<script>
  console.log('Hello, World!');
</script>
```

## Variables and Declarations

```js
var name = 'Aditya';
let age = 26;
const PI = 3.14;
```

- `var`: Function-scoped, can be redeclared
- `let`: Block-scoped, cannot be redeclared
- `const`: Block-scoped, immutable after declaration

## Naming Rules & Best Practices

- Use camelCase.
- Avoid reserved keywords.
- Be descriptive and consistent.

## Data Types

- **Primitive**: string, number, boolean, null, undefined, bigint, symbol
- **Reference**: object, array, function


## Global Execution Context (GEC)

When JS code runs, it creates a **Global Execution Context** which is divided into two phases:

### 1. Creation Phase

- Memory is allocated for variables and functions.
- Variables are initialized as `undefined`.
- Function declarations are hoisted.

### 2. Execution Phase

- Code runs line-by-line.
- Variables are assigned values.
- Functions are invoked and their local execution contexts are created.

This process is what enables **hoisting** and the call stack in JavaScript.

```js
greet();
function greet() {
  console.log('Hello from GEC');
}
```
